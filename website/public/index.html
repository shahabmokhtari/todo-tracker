For ADHD brains and busy weeks

The to-do list that tells you what to do now.

Most task apps show you everything, all the time. Todo Tracker shows you one thing to do now, keeps the rest out of sight until it's due, and lets your AI agents help. Your tasks stay plain markdown files in a folder you own.

due 5 pm #security

Try it: press Mark done or Later. The next thing takes its place. Nothing else asks for your attention.

Why it works

  • One focus, not fifty

    A big card says what to do now. The rest waits below, in the order you chose. Something new never takes over your focus.

  • Later means later

    Snooze a task and it leaves the list. It comes back on time, with a reminder. Nothing rots at the top.

  • Your tasks are your files

    One markdown file per task, in a folder you own. Open it in Obsidian, edit it anywhere, keep every version.

Features

Everything you need to get through the day. Nothing that shouts.

◎

The Do this now card

One task, big and clear, with its reminder, notes and buttons: Mark done, Later, Note, Focus, Timer. Not the right one? Skip moves it down one. Drag the list into your own order and it stays that way.

☾

Snooze choices that say when

Press Later and pick one. Each says when the task comes back.

  • 15 minutes
  • An hour
  • 3 hours
  • This evening
  • Tomorrow morning
  • In 2 days
  • Next Monday
  • In a week
  • In a month

Or type it the way you'd say it (fri 14:30, next week), or wait until another task is done.

✎

Notes on every card

Jot down where you got to, right on the card. The task you're on shows every note, newest first, with who wrote it: you, or Agent: claude. The browser extension can attach the page you were on.

◔

Focus timer and real breaks

Start a focus session on a task and its time counts on that task. When it ends, a full-screen break reminds you to rest: take it, skip it, or start the next focus now. A timer on every task, and reports that show where your week went.

⚡

Plan for the energy you have

Mark draining tasks ⚡⚡⚡ and easy ones ⚡. Say how much you have in a day. Today tells you "⚡ 4.5 of 10 planned", and the plan turns red before you've planned more than you have.

↻

Repeat in plain words

Type a rule: every weekday, every 2 weeks on Monday, Thursday, every month on the last Friday, every 3 days when done. Done moves it to its next time.

≡

Workstreams: big things get small

Break a project into steps that unlock one at a time. Only the current step shows in Do now. Set a wait between steps ("ring 1 tomorrow") and the next one comes back by itself. A progress bar shows how far along each one is.

＋

Capture a thought in one line

Type tasks the way you think. On Windows, Ctrl+Alt+Space opens quick capture from anywhere.

Sync

The same list on every computer

Your tasks folder stays in step with your other computers through OneDrive, iCloud Drive or a private GitHub gist. With OneDrive or iCloud Drive on the computer, there's nothing to set up.

Changed the same task on two computers? Both changes are kept. If the same line changed on both, you pick which one to keep, or keep both. Nothing you typed is lost.

Want your tasks somewhere else too? Connectors keep a group in step with Notion, Microsoft To Do or a private GitHub repository, and never delete anything on either side.

  • OneDriveUsed first, a work or school account before a personal one.
  • iCloud DriveWhen there's no OneDrive, like on a Mac.
  • A private GitHub gistWhen you pick it. Signs in with the GitHub CLI.

Platforms

Where you work, it's there

Every app follows the same rules: the same Do now order, the same snooze choices, the same repeat rules.

Windows: a sidebar that's always there

It docks to the edge of your screen, so maximized windows don't cover it. Toasts for reminders, Ctrl+Alt+Space to capture, the whole app in its own window, and full-screen breaks on every monitor. Prefer a window? Float it, and keep it on top if you like.

  • Mac

    Available

    A native app with a menu bar glance: the focus task, Done, Later and capture. It runs the same server inside, so it uses the same tasks folder and syncs with your PC. For Apple silicon Macs.

  • Linux

    Available

    A tray app that runs everything. Add a task from the tray, or click it for the full window.

  • Web

    Available

    The whole app in your browser at 127.0.0.1:5317, on this computer only. It comes with every desktop app.

  • Browser extension

    Available

    A side panel for Edge, Chrome and Safari: glance, capture, and notes that keep the page you were on. Not in the stores yet; the app walks you through loading it.

  • iPhone and iPad

    Available

    A native app with Today, snooze, notes, energy and the focus timer. For now it keeps its tasks on the device.

  • Android

    Available

    A native app: Today, quick capture, snooze, notes, task timers, and the focus timer with full-screen breaks. For now it keeps its tasks on the device.

  • Your phone and your computer, together

    Coming soon

    Connect your phone to your computer, and sync your tasks to your phone.

AI agents

Your AI can help with your list

Tell Claude or Copilot what you need to do and it lands in your list. Ask what to work on next. Let an agent log progress or break a project into steps.

You what should I work on now?

Agent Reply to the security review: it's critical and the review closes at 5 pm. Two findings are left. Want me to draft the replies?

You add follow-ups from this meeting: send Maya the API notes by Friday, book the offsite

Agent Added two tasks to Work: Send Maya the API notes (due Fri) and Book the offsite.

  • MCP server

    tt mcp works with Claude Desktop, Claude Code, GitHub Copilot CLI, VS Code, Cursor and other MCP apps. It works on your tasks folder directly, even when the app isn't running.

  • The tt command

    For terminals, scripts and agents that run commands: tt, tt add, tt snooze, tt done. Add --json for scripts.

  • Claude Desktop extension

    Open the .mcpb file and Claude shows an install dialog. That's it.

  • Claude Code and Copilot plugin

    The tools plus a skill that teaches your agent to help well: capture, break down, log, defer, never delete.

# Claude Code
claude mcp add todo-tracker --scope user -- tt mcp

# The plugin, with the skill (Claude Code)
/plugin marketplace add shahabmokhtari/todo-tracker
/plugin install todo-tracker@todo-tracker

Or open ⋯ › Connect an AI app in the app: pick your app and copy one line.

  • Every change says who made it. You'll see "Agent: claude" in the timeline.
  • Every change is a version, so you can undo it.
  • There's no delete tool. Agents can't throw your tasks away.
  • You allow automations first. Hooks an agent adds wait for your OK.

Your files, your computer

Local first. Yours always.

Your tasks are markdown files in Documents/Todo Tracker: one folder per group, one file per task, steps as checkboxes, notes as callouts. Edit them in the app, in Obsidian, in any editor, or with an AI agent. The app picks up the changes.

  • Obsidian-friendly. Keep your tasks in your vault; any task opens in Obsidian.
  • Version history. Every change is a version you can look at and restore (needs git).
  • No account, no telemetry. The app only talks to the services you switch on: sync, connectors, an AI model you add.
  • Only on this computer. The server listens on 127.0.0.1 only, checks the address it was called on, and asks for a 256-bit token.
